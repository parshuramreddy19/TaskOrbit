# TaskOrbit – Personal Productivity & Task Tracking Application

TaskOrbit is a responsive task management application built with React and JavaScript. It helps users organize daily activities, manage priorities, track progress, and stay productive through a clean and intuitive dashboard.

## Features

- Task Management: Create, edit, complete, undo, and delete tasks.
- Priority Management: Organize tasks by High, Medium, and Low priority.
- Project Organization: Group tasks into projects.
- Search and Filters: Search tasks and filter by All, Pending, and Completed.
- Dashboard: View task statistics, completion rates, and priority summaries.
- Calendar: View scheduled tasks by due date.
- Analytics: Track productivity and task completion.
- Notifications: View task-related notifications.
- Local Storage: Retain task data between browser sessions.
- Responsive UI: Navigate the application across desktop and mobile screens.

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

Clone the repository:

//bash
git clone YOUR_GITHUB_REPOSITORY_URL

Navigate into the project:

//bash
cd TaskOrbit

Install dependencies:

bash
npm install

Start the development server:

bash
npm run dev


Open the local URL displayed in your terminal.

## Testing

Run the automated tests:
bash
npm run test

Run ESLint:
// bash
npm run lint

Create a production build:

//bash
npm run build
